# v2.9.1 — Nine quality-of-life fixes from a critique pass

Дата: 2026-11-07 · 291 тест · MIT

Прогон «критиком»: каждое вью снято скриншотом под Xvfb, каждая мелкая
шероховатость — в список. Половина списка — накопившиеся болячки
интерфейса, половина — то, чего не хватало в ежедневной работе.

## Починено

- **Футер сайдбара рисовал буквально «стр. .eml»** — сломанный формат
  счётчика страниц, живший в i18n с самого появления. Теперь счётчик
  честный: `6 .eml · стр. 3 из 6` (EN: `page 3 of 6`), без открытой
  страницы — тире.
- **Плейсхолдер поиска был захардкожен по-английски** («Search pages»)
  даже в русской локали; то же — с сообщением пустого хранилища и кнопкой
  «New page». Всё три строки локализованы.
- **Строки задач без даты показывали обрезанное «YYYY-MM…»** — каждая
  строка секции «Без даты». Теперь тихое «—», а полный формат
  `YYYY-MM-DD` переехал в тултип при наведении на ячейку даты.
- **Подписи узлов графа обрезались на 18 символах** («Meeting notes —
  va…») — теперь 26 («Meeting notes — vault sync» влезает).

## Добавлено

- **Восстановление сессии.** Открытая страница (по Message-ID — порядок
  хранилища может меняться) и активное вью сохраняются в `ui_state.json`
  и открываются при следующем запуске. Флаги `--page`/`--view` по-прежнему
  сильнее, страница, удалённая на диске, откатывает к корню хранилища.
- **Счётчик слов** рядом с числом блоков в мета-строке страницы
  («2 блока · 39 слов») с правильными русскими формами (1 слово / 3
  слова / 39 слов). Код, id пунктов и ключ `language` словами не считаются.
- **«/» фокусит поиск в сайдбаре из любого места** (как в Gmail); свёрнутый
  сайдбар сам разворачивается. Не срабатывает, пока клавиатура у палитры
  команд или текстового поля.
- **Очистка поиска**: ✕-кнопка у правого края поля плюс Esc при фокусе.

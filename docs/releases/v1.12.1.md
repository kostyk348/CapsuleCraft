# CapsuleCraft v1.12.1 — Native-only releases, Integrations fixes

## The headline

Releases now carry **native builds only**. The Tauri/web installers (MSI,
NSIS, deb, rpm, dmg) are retired — the egui shell is the app, and every
artifact on the release page is exactly that:

- **Windows x64** — `CapsuleCraft_native_1.12.1_x64.zip` (portable, zero deps,
  no WebView2, no installer)
- **Linux amd64** — `CapsuleCraft_1.12.1_amd64.AppImage` (zero-dependency)
- **macOS** — `CapsuleCraft_native_1.12.1_macos_universal.app.zip` — new
  **universal binary**: Apple Silicon and Intel in one `.app`

Every release also ships the mistral.rs OCR engines (`mistralrs-engine-*.tar.gz`,
used by the in-app Integrations catalog) and a unified `SHA256SUMS.txt`.

## Fixed

- **Integrations modal swallowed clicks.** The dialog was only painted while
  a full-screen click backdrop sat underneath: poking anywhere that missed a
  button — status pills, progress bars, empty card space — closed the whole
  modal mid-interaction. The panel now claims its own click area; dismissing
  works by clicking the dimmed backdrop outside the dialog or pressing Escape.
- **TTS voices could install a broken runtime.** The catalog downloaded
  sherpa-onnx v2.0.1 while the FFI mirrors `c-api.h` at **v1.12.40** (v2.0.1
  removed the `data_dir` phonemization argument and shifts struct layouts).
  The runtime component now downloads v1.12.40, and a regression test welds
  the URL to the FFI tag so the two cannot drift again.
- **OCR engine downloads outlived releases.** `mistralrs-engine-*.tar.gz` is
  now fetched through the `releases/latest` redirect instead of a hard-coded
  `v1.12.0` URL.

## Upgrade notes

- Web/Tauri installers are no longer produced. If you previously installed
  the web build (MSI/NSIS/deb/dmg), remove it and switch to the native
  artifacts above — the Integrations catalog and the rest of the native
  feature set live only in the egui shell.
- The macOS artifact replaces the previous arm64-only zip with a universal
  build; Intel Macs are supported again.

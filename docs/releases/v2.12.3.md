# v2.12.3 — поиск, который заканчивает мысль

Дата: 2026-11-08. Ветка: `feat/v2.12.3-search-qol`. QoL-волна поверх смёрженного
PR #69 (интерактивный граф). Правило волны: ничего не ломать — каждое изменение
поведения накрыто headless-тестом, все 336 зелёные.

## 1. Создание страницы прямо из поиска

Когда поиск в сайдбаре ничего не находит, пустое состояние предлагает
«Создать страницу “запрос”» — клик или Enter (поле и так владеет клавиатурой).
Страница создаётся с введённым заголовком, поиск очищается, каретка сразу в
заголовке новой страницы. Shell переиспользует `create_page_titled` — тот же
путь, что и wiki-ссылки: тост, сохранение, обновление ссылок.

## 2. Esc очищает поиск

Первый Escape при сфокусированном поле очищает запрос, второй (поле уже
расфокусировано) уходит в глобальные обработчики, как раньше. Ради корректной
семантики пришлось разобраться с двумя ловушками egui:

- однострочный TextEdit surrender'ит фокус ещё во время обработки входящего
  Escape, поэтому `memory.focused()` к моменту отрисовки виджетов уже пуст —
  фокус поля запоминается из предыдущего кадра (temp-память
  `sidebar-search-focus`);
- флаг читается до захвата write-лока контекста: методы `Response` ходят через
  тот же RwLock, вложенный вызов = дедлок (поймано тестом, «Failed to acquire
  RwLock write after 10s»).

## 3. Дата на штампе «изменено N назад»

Штамп в мета-строке страницы при наведении показывает абсолютное локальное
время (`dd.mm.yyyy hh:mm`). Форматирование вынесено в
`NativeApp::edited_absolute_stamp` и накрыто тестом `edited_stamp_format`.

## Тесты (336, headless egui)

- `enter_in_empty_search_requests_page_creation` — Enter на пустой выдаче
  запрашивает создание страницы с введённым заголовком и чистит поле;
- `escape_clears_a_focused_search_without_creating` — Esc чистит запрос и
  ничего не создаёт;
- `edited_stamp_format` — формат штампа dd.mm.yyyy hh:mm.

Попутно путь «Enter открывает верхний результат» переведён на пробу фокуса
начала кадра: старая проба середины кадра на кадре Enter видела поле уже
расфокусированным и молча теряла нажатие.

# v2.12.0 — Android launch fix, the app icon, and the second QoL wave

Дата: 2026-11-08. Ветка: `feat/v2.12.0-android-qol`.

## Главное

1. **Андроид больше не вылетает при запуске.** Причина: крейт собирался с
   бэкендом `android-game-activity` (eframe), а манифест объявлял
   `android.app.NativeActivity`. В `.so` генерировался `GameActivity_onCreate`,
   но не `ANativeActivity_onCreate` — NativeActivity не могла привязаться к
   библиотеке и приложение умирало мгновенно. Фикс: eframe объявлен по-таргетно
   (features аддитивны, accesskit на десктопе, `android-native-activity` на
   андроиде — eframe 0.37 запрещает связку accesskit+native-activity).
   Верификация: `cargo tree -e features` на android-таргете показывает ровно
   нужный набор; сборка .so — гейт CI Android job.

2. **У APK появилась иконка** (до этого — системный робот): генератор
   `scripts/gen_android_icon.py` (PIL) строит легаси/круглую/adaptive-иконку
   в бренд-палитре приложения (Graphite #121316 + акцент #2D81FF, капсула).

3. **Вторая волна QoL — 30+ пунктов**: навигация (Alt+Right, Ctrl+1..9,
   Ctrl+Tab, N/F2/Delete, память скролла, Ctrl+Home/End), сайдбар (пины,
   недавние, сортировка с сохранением, Enter/стрелки в поиске, статистика),
   документ («изменено N мин назад», перенос строк, копия в Markdown/текст,
   шаблоны страниц), шелл (recents в палитре, путь хранилища, шпаргалка
   Shift+/, версия в FAQ, размер окна).

## Известные ограничения

- AccessKit на Android недоступен с NativeActivity-бэкендом в eframe 0.37 —
  доступность на этой платформе держится на контрасте и размерах самого UI.
- Сборка APK в CI не проверялась на реальном устройстве в этой песочнице;
  фикс подтверждён анализом бэкенда android-activity + разрешением фич.

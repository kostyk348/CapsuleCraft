# CapsuleCraft v2.6.0 — a pen for the board

The canvas roadmap closes: **freehand drawing**. Alongside the ride, a
long-standing flake in the STT test suite went away — it was the one
that painted the native CI job red on the v2.5.0 release merge.

## Freehand strokes

The canvas toolbar gains a **«Рисовать»** toggle (a new `Icon::Pen`).
While the pen is on, a drag on the empty field draws instead of pulling
a marquee — nodes still drag and select, and panning (middle mouse /
space) keeps working. Points are collected in world coordinates and
decimated: a new point is recorded only after the cursor moved 1.5
screen pixels, so a slow wiggle cannot bloat the capsule.

A stroke lands as an ordinary element, `{type: "ink"}`: its bounding
box goes to `x/y/width/height` — so dragging, marquee selection, «Fit»
and Delete treat it like any other element — while the points are
stored relative to the bbox origin, rounded to 0.1. Rendering is a
polyline; a single click draws a dot. The stroke preview follows the
cursor live, undo snapshots right before the element is committed, and
the pen flag persists in the canvas data the same way the grid snap
does. Strokes have no text: no inline editor on double-click, no
connector port; arrows still anchor to the bbox like on any node.

## The red CI, explained and fixed

«Native egui shell» failed on the v2.5.0 release merge with
`start_rejects_when_missing_model` asserting the STT busy-flag right
after `start()`. The worker thread fails a `/nonexistent` model dir in
microseconds and can flip the shared map `Running → Failed` before the
main thread reaches the assert — a scheduling race, not a feature
regression (the same test passed on #50 and failed on #51). The fix
keeps the production signature untouched: `start()` delegates to a
private `start_with()` whose worker closure is injectable, and the test
gates a fake worker behind a channel, then waits for the failure with a
bounded poll instead of a blind 300 ms sleep. Stressed 200/200 runs
with `-j 1` (CI parity).

## Tests

- Ink bbox spanning and degenerate cases (empty, single point).
- Relative-points round-trip through `ink_element`/`ink_points`
  (0.1 rounding tolerance); dot strokes get a 1×1 bbox.
- JSON serialize/parse keeps the stroke.
- Headless draw with the pen on and off.

Native suite: 263 → **268** passed, 0 failed, 2 ignored.

## Upgrade

Usual paths: the AppImage, the `.deb`, the macOS universal `.dmg`, the
Windows NSIS installer or the portable zip. `.eml` capsules stay
compatible: a stroke is one more element in `page-canvas.json` / the
canvas block data.

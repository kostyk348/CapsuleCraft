# CapsuleCraft v1.12.2 — the Integrations button actually opens; installers

## Fixed

- **Clicking ⚙ Integrations did nothing at all.** The v1.12.0 branch added the
  `open_integrations` flag and the title-bar chip, but `ShellAction::absorb` —
  the step that merges title-bar actions back into the app shell — never
  copied the new field. The click was silently dropped, so the catalog never
  opened (v1.12.1 fixed clicks *inside* the dialog; this fixes opening it).
  A new headless end-to-end test now drives the real app frame with synthetic
  mouse clicks and sweeps the title bar, so a dead chip can never ship again.
- The catalog is also reachable from the command palette: ⌘K → "Интеграции /
  Integrations".

## Installers for every platform

Downloads are proper installers now — not bare archives:

| Platform | Installer | Also |
|---|---|---|
| Windows x64 | `CapsuleCraft_1.12.2_x64-setup.exe` — NSIS: Start-menu & desktop shortcuts, uninstaller, registry entry | `CapsuleCraft_native_1.12.2_x64.zip` (portable, zero deps) |
| macOS (Apple Silicon + Intel) | `CapsuleCraft_1.12.2_macos_universal.dmg` — drag-to-Applications | — |
| Linux amd64 | `CapsuleCraft_1.12.2_amd64.deb` — `sudo apt install ./…`, menu entry, icon | `CapsuleCraft_1.12.2_amd64.AppImage` (zero-dependency) |

Every release still carries the mistral.rs OCR engines
(`mistralrs-engine-*.tar.gz`, used by the in-app Integrations catalog) and a
unified `SHA256SUMS.txt`.

## Upgrade notes

- If you installed the v1.12.1 portable zip, just run the new setup.exe over
  it — or keep using the zip; both ship the same binary.
- The macOS `.dmg` replaces the previous `.app.zip` download.

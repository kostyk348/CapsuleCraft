# v2.11.0 — пять багфиксов и волна QoL

Дата: 2026-11-08 · 313 тестов · MIT

Прогон по списку дефектов от пользователя: все пять пунктов закрыты,
сверху — волна QoL-улучшений в UX/UI. 310 → 313 тестов.

## Починенные баги

### 1. Чекбоксы не кликались
Корень: кастомный виджет `checkbox()` в `widgets/controls.rs` построен на
`allocate_exact_size(Sense::click())`. egui НЕ выставляет флаг `CHANGED`
таким виджетам сам — его нужно звать через `mark_changed()`. Поэтому все
обработчики вида `if checkbox(ui, &mut done).changed()` в planning-списке
и todo-блоках молча не срабатывали: галочка мигала и откатывалась.

Фикс одной строкой в виджете — все места использования починились сразу.
Диагностика велась headless-тестом с инъекцией событий egui
(`checkbox_click_toggles_the_task`): сканирование позиций клика показало,
что клик получает чекбокс, а не оверлей строки, и теряется уже после.
Семантический тест `minimal_overlay_vs_checkbox_semantics` защищает
hit-test (оверлей строки против чекбокса) от регрессий.

### 2. Insert-меню закрывалось при перетягивании вниз
«+»-попап в gutter'е блока рендерился внутри гейта `if hovered` — а попап
egui живёт, только пока каждый кадр зовётся `show()`. Курсор уходил с
строки в само меню (вниз) → `hovered` = false → `show()` не вызван → меню
умерло. Теперь интеракт и попап регистрируются каждый кадр; под hover-гейтом
осталась только отрисовка иконки.

### 3. Нумерация — только в мультитреде
Строки ответов в Threads получили номер позиции в цепочке (`1.`, `2.` …,
mono, приглушённый). Сайдбар остался без номеров — там обычные заголовки.

### 4. Страницы импортированных писем показывались «странно»
Page-режим показывал только баннер «файл не создан CapsuleCraft» и уносил
текст письма в Email-вкладку. Теперь тело письма (text/plain, а для
HTML-писем — текст, вычищенный новым `mime::html_to_plain_text`) рендерится
на странице, только для чтения, с кнопкой «Скопировать текст письма».

### 5. Синхронизация
- **IMAP не обновлял существующие письма.** Совпадение Message-ID означало
  «пропустить навсегда». Теперь: если серверная копия новее локальной (с
  допуском 2 с на расхождение часов) и дайджест тела отличается — локальный
  файл перезаписывается, в отчёте появляется `N updated`.
- **«Где синхронизация без почты?»** Папковая синхронизация существовала,
  но была доступна только через маленькую иконку в футере сайдбара. Теперь
  есть подписанный пункт «Синхронизировать папку» в меню хранилища и команда
  «Sync folder now» в палитре (Ctrl+K).

## QoL-волна

1. `J`/`K` — следующая/предыдущая страница (не срабатывает, когда поле
   ввода держит клавиатуру).
2. `Alt+←` — назад по стеку посещённых страниц (до 64 шагов).
3. `F5` — перечитать хранилище с диска (сохраняем несохранённое перед
   перечиткой) + тост с числом страниц.
4. `Ctrl+F` — фокус в поиск по страницам (одноразовый флаг через egui
   storage).
5. `Ctrl+D` — дублировать страницу: блоки, теги, тело; новая идентичность;
   тост.
6. `Ctrl+K`-палитра: «Duplicate page», «Copy page link» (`capsule://id`),
   «Reload vault from disk», «Sync folder now».
7. Заголовок окна ОС показывает открытую страницу: «Тема — CapsuleCraft».
8. Оценка времени чтения (~200 слов/мин) в мета-строке страницы, если
   текста достаточно.
9. `EditorAction::toast` — тосты можно поднимать и из редактора (используется
   кнопкой копирования текста письма).
10. Тело письма в Page-режиме (см. баг 4) — тоже QoL.
11. Нумерация тредов (см. баг 3) — QoL.
12. Подписанная папковая синхронизация (см. баг 5) — QoL.

Плюс ранее существовавшие, проверенные в этом прогоне: счётчик результатов
поиска («N · found»), Esc очищает поиск, IMAP-кнопка «Проверить связь»,
сохранение последней вьюхи и страницы между сессиями.

## Известное

Папковая синхронизация (два каталога .eml) уже обновляет файлы по mtime
(«последний писавший побеждает», допуск 2 с) — в этом прогоне проверена
существующими тестами sync.rs; IMAP-обновление покрыто тем же механизмом
дайджестов и вручную по коду (живой IMAP-сервер в песочнице недоступен).

# Email (IMAP) Synchronization in CapsuleCraft Native

## Обзор архитектуры

В соответствии с планом [plan_04_email_imap_sync.md](file:///c:/Users/Kobalt/.gemini/antigravity/brain/03df524e-b2c5-4b9e-869d-32a6d3e64e03/plan_04_email_imap_sync.md) реализована встроенная децентрализованная синхронизация базы заметок через почтовые ящики пользователей по протоколу **IMAP**.

Так как каждая страница в CapsuleCraft хранится как валидный RFC 5322 MIME-файл (`.eml`), почтовый ящик пользователя (Gmail, Яндекс, Fastmail, Mail.ru, Dovecot) выступает в роли бесплатного, безопасного облачного бэкенда без сторонних серверов.

---

## Что реализовано

### 1. Модуль синхронизации `native/src/sync_imap.rs`
- **Конфигурация `ImapConfig`:**
  - `enabled: bool` — флаг активности синхронизации;
  - `host: String` — адрес IMAP-сервера (напр., `imap.gmail.com`, `imap.yandex.ru`);
  - `port: u16` — порт с TLS-шифрованием (по умолчанию `993`);
  - `username: String` — email / логин;
  - `password: String` — пароль приложения (App Password);
  - `folder: String` — целевая папка (по умолчанию `"CapsuleCraft"`);
  - Хранение параметров в локальном файле `vault/.capsule-sync.json`.
- **Проверка подключения `test_connection()`:**
  - Валидация TLS-рукопожатия и аутентификации на сервере;
  - Автоматическое создание папки `CapsuleCraft`, если её ещё нет на сервере.
- **Двусторонний движок `run_sync()`:**
  - **Pull (Входящие с сервера):** Считывает `UID` и заголовки `ENVELOPE` удаленных сообщений. При обнаружении новых писем (созданных на других устройствах или отправленных со смартфона) скачивает `BODY[]` и сохраняет как `.eml` в хранилище `vault/`.
  - **Push (Исходящие на сервер):** Сверяет `Message-ID` локальных файлов с сервером. Если капсулы нет в почтовой папке, загружает её методом `APPEND`.

### 2. Интерфейс пользователя (egui UI)
- **Модальное окно настроек IMAP:**
  - Диалог с полями для сервера, порта, логина, защищенного ввода пароля приложения и папки;
  - Кнопки: «Проверить связь» (Test Connection), «Синхронизировать сейчас» (Sync Now) и «Сохранить настройки»;
  - Отображение текущего статуса проверки / синхронизации в реальном времени.
- **Индикатор в заголовке окна (Title bar):**
  - Кнопка с иконкой `IMAP` и векторной точкой статуса:
    - Зелёная: синхронизировано;
    - Оранжевая / бета: выполняется синхронизация;
    - Красная: ошибка подключения / авторизации;
    - Серая: синхронизация выключена.
- **Командная палитра (`Ctrl+K`):**
  - `Синхронизировать сейчас (IMAP)` (`Ctrl+Shift+S`);
  - `Синхронизация почты (IMAP)` — открытие диалога настроек.
- **Двуязычная локализация (i18n):**
  - Полная поддержка RU и EN для всех элементов UI, подсказок и сообщений об ошибках.

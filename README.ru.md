## Что такое CapsuleCraft?

Настольное приложение для мышления. Каждая страница — настоящий файл почтового
формата (`.eml` — RFC 5322 / RFC 2045): откройте его в Thunderbird, найдите
через `grep`, сравните в `git`, забэкапьте через `rsync`, синхронизируйте
Syncthing'ом. CapsuleCraft добавляет сверху редактор, поиск, планирование и
структуру — а файлы остаются вашими.

- 🗂 **Ноль баз данных** — папка с `.eml`-файлами и есть вся база знаний.
- 🛰 **Офлайн по дизайну** — парсинг, поиск, AI и планирование работают локально; приложение само не ходит в сеть.
- 🎨 **Восемь полных тем** — Graphite, Paper, Nord, Gruvbox, Catppuccin, Solarized, Everforest и Rosé Pine, плюс личный акцентный цвет и масштаб интерфейса 80–140 % поверх любой из них.
- 🤖 **Офлайн Co-Thinker** — детерминированная локальная критика и анализ данных. Без API-ключей и облака.
- 🧩 **Скачиваемый локальный AI** — OCR (Xiaomi-OCR-0 на движке на Rust), распознавание речи (whisper) и синтез речи ставятся из каталога «Интеграции» и работают полностью офлайн.
- 🖥 **Крошечный нативный шелл** — Rust + egui, без браузерного движка. Ставится как AppImage **без единой бандл-библиотеки**.

CapsuleCraft стартует **пустым** — ни демо-заметок, ни наполнителя. Двуязычный
**интерактивный тур онбординга** (открывается сам при первом запуске, 12 шагов,
с кнопками «попробовать», ведущими прямо в живую функцию) и встроенный **FAQ**
(`F1`, `ⓘ FAQ` или палитра команд) объясняют хранение, поиск и перенос данных
прямо внутри приложения.

## Возможности

- **Блочный редактор** — заголовки, абзацы, списки задач, коллауты, блоки кода,
  CSV-датагриды, заметки с аудио-вложениями; автосохранение, undo/redo,
  круговой путь `.eml` без потерь.
- **`[[Вики-ссылки]]`** — парсятся из текста страницы, кликабельны, с живым
  индексом обратных ссылок («Откуда ссылаются»); переименование страницы
  переписывает каждую ссылку.
- **Поиск** — Okapi BM25 по всему хранилищу с оценками релевантности,
  подсветкой сниппетов и регистронезависимостью с учётом кириллицы; «Похожие по
  смыслу» ранжирует страницы по tf-idf косинусной близости по тому же индексу.
- **Планирование** — все задачные блоки хранилища собираются в Повестку,
  Канбан, Гантт (стрелки зависимостей и защита от циклов) и двухпанельный
  календарь: любой план открывает свою страницу кликом — по строке, чипу или
  полосе Ганта — а чип, перетащенный на другой день, переносит срок. Экспорт
  в RFC 5545 ICS.
- **Темы** — восемь полных пресетов (Graphite, Paper, Nord, Gruvbox, Catppuccin,
  Solarized, Everforest, Rosé Pine) в пикере в стиле Obsidian: карточки тем с
  живыми свотчами, личный акцент поверх любого пресета и масштаб интерфейса
  80–140 %. Всё сохраняется в `native-appearance.json` — скопируйте один файл на
  новую машину, и оформление переедет с ним.
- **Интерактивный онбординг** — двуязычный тур из 12 шагов открывается при
  первом запуске и остаётся доступным из ⌘K («Обзор приложения / Onboarding
  tour»): он проходит по каждой функции, а кнопки «попробовать» открывают
  настоящее — палитру команд, пикер тем, граф, каталог интеграций.
- **Project Knowledge Engine** — превратите дерево исходников в базу знаний:
  инкрементальный скан (FNV-1a + кэш по mtime, перескан 500 файлов быстрее
  30 мс) питает парсер сигнатур/докстрингов для восьми языков (Rust,
  TypeScript, JavaScript, Python, Go, C#, Java, Dart) плюс Markdown-доки;
  результат ложится `.eml`-капсулами в `.capsule/` с реестром техдолга и
  сгенерированными агентскими скиллами для MCP-клиентов. Осиротевшие капсулы
  чистятся автоматически при переименовании или удалении исходника. Весь
  движок — парсер, кэш, скиллы и складывание папок в сайдбаре — принёс
  [@kobaltgit](https://github.com/kobaltgit) (см.
  [docs/PROJECT_KNOWLEDGE_ENGINE.md](docs/PROJECT_KNOWLEDGE_ENGINE.md)).
- **Треды** — ответы это настоящие дочерние `.eml` с `In-Reply-To`/`References`,
  ровно как в почте. Ваше дерево рассуждений — стандартный почтовый трединг.
- **Датасеты** — CSV/JSON ездят MIME-частями, адресуемыми по `Content-ID`;
  блоки-датагриды рисуют их таблицами — а формульные ячейки вида
  `=SUM(A1:A5)` считает встроенный офлайн JS-движок boa прямо в нативном
  шелле.
- **Нативная запись и воспроизведение звука** — записывайте голосовые заметки
  прямо из аудио-блока (cpal → 16-бит PCM WAV, живой индикатор уровня) и
  слушайте MIME-аудио в egui-шелле (rodio: WAV/MP3/OGG/FLAC) с
  play/pause/stop, скрабом и громкостью.
- **Шифрование капсул OpenPGP** — любую капсулу можно экспортировать как
  бронированный `.eml.asc` с шифрованием по парольной фразе (AES-256, SEIPD v1
  через rPGP) и импортировать обратно тем же диалогом; полностью офлайн, без
  бинаря gpg.
- **Офлайн-исполнение кода** — REPL-блоки JavaScript работают в нативном шелле
  через встроенный boa; JSON-блоки валидируются
  и красиво печатаются; Python/Rust честно сообщают, что интерпретатора в
  zero-dependency-сборке нет.
- **Импорт** — бросайте `.eml`-файлы в окно (байт-в-байт), импортируйте с IMAP
  или мигрируйте существующее хранилище Obsidian (`--import-obsidian`).
- **Готов к AI-агентам** — выставите хранилище по
  [MCP](https://modelcontextprotocol.io), и Claude, Cursor или любой MCP-клиент
  сможет читать и искать вашу базу знаний. Встроенный Co-Thinker вместо этого
  спорит с вашими тезисами офлайн.
- **Встроенный FAQ + snapshot CLI** — `--snapshot` рендерит настоящее окно в PNG
  (именно так сделан каждый скриншот выше). Интерфейс RU/EN, а английская
  локаль на 100 % латиница — под защитой юнит-теста.

## Почему `.eml`?

Большинство приложений запирают знания в базе данных, которая умирает вместе с
приложением. CapsuleCraft переворачивает это: одна страница = один текстовый
файл на диске.

| | Типичное PKM-приложение | CapsuleCraft |
|---|---|---|
| Хранение | закрытая база | обычные `.eml`-файлы |
| Чем открыть | только само приложение | любой почтовый клиент, `grep`, `git` |
| Экспорт | конвертация с потерями | файл и есть экспорт |
| Миграции | обновления приложения | не нужны никогда |
| Телеметрия / аккаунты | как повезёт | нет — папка и есть приложение |

## Формат капсулы

```eml
Message-ID: <capsule-1755000000000@vault.local>
Subject: Q4 pricing experiment
From: Owner <owner@vault.local>
To: Vault <vault@capsuleos.local>
X-Capsule-Tags: pricing, experiment

--capsule-boundary
Content-Type: application/json; name="blocks.json"
Content-ID: <blocks_json>

[{"id":"blk_1","type":"heading","data":{"level":1,"text":"Q4 pricing experiment"}}]
--capsule-boundary
Content-Type: text/csv; name="cohorts.csv"
Content-ID: <dataset_cohorts_csv>

cohort,users,conversion
Q4-A,1200,0.041
--capsule-boundary--
```

JSON-часть — структурированный блочный холст; остальные части это датасеты и
вложения, адресуемые по `Content-ID` из блоков-датагридов. Треды ездят на
стандартных почтовых заголовках.

## Как CapsuleCraft сравнивается

| | **CapsuleCraft** | Obsidian | OneNote | Notion |
|---|---|---|---|---|
| Формат хранения | обычный `.eml` (открытый стандарт) | Markdown + скрытые данные приложения | проприетарные бинарные секции | проприетарная облачная база |
| Полностью офлайн | ✅ по дизайну | ✅ | ⚠️ в основном | ⚠️ ограниченно |
| Нужен аккаунт | ❌ никогда | ❌ (платная синхронизация требует) | ✅ аккаунт Microsoft | ✅ для синхронизации |
| Данные читаются без приложения | ✅ Thunderbird / mutt / `grep` | ✅ Markdown | ❌ | ❌ (только экспорт) |
| `git`-диффы, `grep`, `rsync` | ✅ нативно | ✅ | ❌ | ❌ |
| Настоящий почтовый трединг | ✅ `In-Reply-To`/`References` | ❌ | ❌ | ❌ |
| Темы и свой акцент | ✅ 8 пресетов + акцент + масштаб | ✅ (комьюнити-темы) | ⚠️ только тёмный режим | ⚠️ ограниченно |
| Локальный детерминированный AI | ✅ Co-Thinker | ⚠️ плагины/облако | ⚠️ Copilot (облако) | ⚠️ облако |
| Открытый код | ✅ MIT | ❌ (бесплатно, но закрыто) | ❌ | ❌ |
| Размер установки (Linux) | ~11 МБ AppImage, без вебвью | ~100 МБ Electron | 100+ МБ | веб-приложение |
| Vendor lock-in | нет | низкий | высокий | высокий |

**Где Obsidian/OneNote выигрывают сегодня:** экосистема плагинов Obsidian,
глубина стилуса/инкинга OneNote, совместное облачное редактирование Notion.
CapsuleCraft сознательно уже: локальное хранение, которому можно верить десятилетиями.

## Сильные стороны

- **Данные переживут приложение.** Удалите CapsuleCraft завтра — Thunderbird
  всё равно откроет каждую заметку. Никаких миграций и конвертаций. Никогда.
- **Приватность структурна.** Ни аккаунтов, ни телеметрии, ни API-ключей,
  ни сетевых вызовов. AI работает офлайн, потому что это единственный честный вариант.
- **Маленький и быстрый.** В нативном шелле нет браузерного движка: AppImage
  на 8–12 МБ, мгновенный старт, зависимости только glibc.
- **Честный запуск.** Стартует с пустым хранилищем, 12-шаговым туром и
  встроенным FAQ — никаких демо-заметок, притворяющихся данными. Известные
  пробелы перечислены в [LIMITATIONS.md](LIMITATIONS.md), а не спрятаны в маркетинге.
- **Есть путь миграции.** Импортёр Obsidian, IMAP-синхронизация и импорт `.eml`
  дадут настоящий контент в первый же день.

## Начало работы

### Скачать

**Нативный AppImage** (рекомендуется, Linux) или **.deb**-пакет:

```bash
chmod +x CapsuleCraft_2.9.0_amd64.AppImage
./CapsuleCraft_2.9.0_amd64.AppImage            # хранилище по умолчанию...
./CapsuleCraft_2.9.0_amd64.AppImage /path/to/vault   # ...или ваша папка
# или deb:
sudo apt install ./CapsuleCraft_2.9.0_amd64.deb
```

Нужны только glibc, десктоп X11 или Wayland и (для звука) ALSA — ни WebKitGTK,
ни WebView2, ничего больше. Каждый GitHub-релиз несёт и `SHA256SUMS.txt`.

**Нативный установщик Windows** (x64) — `CapsuleCraft_2.9.0_x64-setup.exe`
(NSIS: ярлыки в «Пуск» и на рабочем столе, деинсталлятор). Хотите портативно?
Берите `CapsuleCraft_native_2.8.0_x64.zip`: распакуйте и запустите
`CapsuleCraft.exe`. Стandalone-нативный egui-шелл, ноль зависимостей, WebView2
не нужен.

**Нативное приложение macOS** (универсальное: Apple Silicon + Intel) —
`CapsuleCraft_2.9.0_macos_universal.dmg`: откройте, перетащите
`CapsuleCraft.app` в Applications. Подпись ad-hoc; если Gatekeeper заблокирует
первый запуск, выполните `xattr -d com.apple.quarantine /Applications/CapsuleCraft.app`.

Релизы несут **только нативные сборки** — унаследованный веб-движок удалён из
репозитория в v2.9.0, веб/Tauri-установщиков не существует.
Linux **AppImage / .deb**, Windows **setup.exe** и macOS **.dmg** — это и есть
приложение: без браузерного движка и библиотек вебвью.

#### Где живут данные

Компоненты (движки OCR/STT/TTS и модель OCR на 1.75 ГБ), указатель активного
хранилища и недавние хранилища едут в **каталог данных**: `%APPDATA%\com.capsuleos.app`
(Windows), `$XDG_DATA_HOME/com.capsuleos.app` или `~/.local/share/com.capsuleos.app`
(Linux/macOS). Настройки (тема, зум, свои папки моделей) едут в **каталог
конфигурации**: `~/.config/capsuleos` или `$XDG_CONFIG_HOME/capsuleos`. Оба
независимы от того, где лежит AppImage, .deb или портативный бинарь — обновление
никогда не трогает ваши движки и модели. Портативный запуск может перенести оба
каталога:

```bash
CAPSULECRAFT_DATA_DIR=/mnt/usb/capsulecraft-data ./CapsuleCraft_amd64.AppImage
CAPSULECRAFT_CONFIG_DIR=/mnt/usb/capsulecraft-config ./CapsuleCraft_amd64.AppImage
```

> Первый запуск показывает пустое хранилище, **тур онбординга** (12 двуязычных
> шагов — смело пропускайте, он не навязывается и живёт в ⌘K) и встроенный
> **FAQ**. Жмите `F1`, кнопку `ⓘ FAQ` или ⌘K → FAQ. Демо-заметки не создаются никогда.

### Сборка из исходников

```bash
git clone https://github.com/kostyk348/CapsuleCraft.git
cd CapsuleCraft/native
cargo run --release -- /path/to/your/vault
```

Требования только нативные: Rust stable, никаких зависимостей GUI-тулкитов.

### Snapshot CLI (доки/CI)

```bash
cargo run --release -- --snapshot out.png --page 1 [--view graph] [--search "query"] [--onboarding]
```

Чтобы пересоздать скриншоты README: `cargo test generate_demo_vault --
--ignored` пишет демо-хранилище на шесть страниц в `/tmp/capsule-demo-vault`,
затем запустите бинарь с `--snapshot` под Xvfb (точный цикл описан в
`docs/releases/v2.2.0.md`).

## Архитектура (нативный шелл)

```text
native/src/
  main.rs        вход, разбор аргументов, модалки, snapshot CLI
  cli.rs         типизированный CLI
  theme.rs       8 пресетов тем, акцент, масштаб шрифта, персистентность
  mail.rs        парсинг и сериализация RFC 5322 / MIME
  mime.rs        разделение частей, реестр Media-Type, датасеты
  blocks/        рендереры блоков: paragraph, todo_list, callout, grid, code…
  links.rs       [[вики-ссылки]], индекс обратных ссылок
  graph.rs       DAG связей капсул
  threads.rs     трединг по In-Reply-To / References
  planning.rs    повестка / канбан / гантт, экспорт ICS
  search.rs      BM25-индекс по всему хранилищу
  project_parser.rs  Project Knowledge Engine (кодовая база -> .capsule/)
  project_skill.rs   сгенерированные агентские скиллы
```

## Ограничения (честные)

См. [`LIMITATIONS.md`](LIMITATIONS.md). Главное: воспроизведение аудио
покрывает WAV/MP3/OGG/FLAC (записанный в браузере webm/opus требует
конвертации), JS-движок не исполняет таймеры и I/O, а синхронизация —
двустороннее слияние папок без встроенного облачного транспорта.

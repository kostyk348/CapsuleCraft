# Security policy

## Supported versions

Fixes land on the latest release line. Older tags are not patched — upgrade to the newest
release, they are cheap to install.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's private reporting:

- https://github.com/kostyk348/CapsuleCraft/security/advisories/new

Please include: affected version/tag, platform, a reproduction (file or command), and the
impact you expect. If the issue is in a dependency, say which one and its version.

You can expect an initial reply within a few days. Credit is given in the release notes
unless you prefer otherwise.

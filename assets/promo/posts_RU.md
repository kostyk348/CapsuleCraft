## 1. Telegram (канал) — с demo.gif

**Локальный ИИ, который вы скачиваете сами: CapsuleCraft v1.12.0**

CapsuleCraft — база знаний без базы данных: одна страница = один настоящий `.eml`-файл (RFC 5322). Его открывает Thunderbird, находит `grep`, диффает `git`, синхронизирует Syncthing. Приложение можно удалить — данные переживут его.

Что нового в v1.12.0 — каталог **⚙ Интеграции**: офлайн-движки, которые появляются в приложении только после явного скачивания. Ничего не вшито:

■ **OCR** — Xiaomi-OCR-0 на чисто-растовском движке mistral.rs: нажимаете ✨ на вложении-картинке — распознанный текст ложится в заметку;
■ **STT** — whisper (tiny/base/small) прямо внутри приложения: «Расшифровать запись» под аудио-блоком;
■ **TTS** — русские голоса Ирина и Дмитрий: страница читается вслух кнопкой 🔊;
■ **PDF и просмотр картинок** — нативно, без внешних программ.

Всё это работает полностью офлайн: ни API-ключей, ни облака, ни телеметрии. Компоненты ставятся в каталог приложения — папка хранилища остаётся папкой `.eml`.

И это поверх уже умеемого: блочный редактор с `[[вики-ссылками]]`, поиск BM25 со сниппетами, планирование Agenda/Kanban/Gantt с экспортом ICS, почтовые треды, OpenPGP-шифрование капсул, запись с микрофона, офлайн Co-Thinker и MCP-сервер для агентов.

### Мотивация

Инструменты для заметок принято мерить функциями. Я предлагаю мерить иначе: что произойдёт с вашими записями, если проект завтра закроется? Для Obsidian ответ «ничего страшного» — Markdown читается где угодно. Для Notion и OneNote ответ заметно грустнее: проприетарная база, экспорт через боль, и десять лет заметок привязаны к чужому серверу или бинарному формату.

CapsuleCraft доводит идею «данные переживают приложение» до логического предела: **одна страница = один файл `.eml`** — самое обычное письмо по RFC 5322 с MIME-частями для данных. Никакой своей базы данных нет вообще — ни SQLite, ни leveldb, ни реестра. Вся база знаний — папка, которую открывает любой почтовый клиент, находит `grep`, диффает `git` и синхронизирует `rsync` или Syncthing. Приложение можно снести — данные не заметят.

### Главный аргумент: локальный ИИ по собственному выбору

Каждый «умный» блокнот сегодня тянет облако: ваши заметки уезжают на чужие сервера, а за умение думать с вас снимают подписку. В v1.12 мы пошли с противоположной стороны — **каталог «⚙ Интеграции»** в заголовке приложения: офлайн-движки, которые появляются в приложении только после явного скачивания. Ничего не вшито в сборку, ничего не стартует само, ни один байт не уходит в сеть. Каталог показывает размер каждого компонента заранее — вы всегда знаете, на что подписываетесь.

Что в каталоге:

**OCR — Xiaomi-OCR-0 на mistral.rs.** Модель 0.8B (гибридное внимание, Apache-2.0, 1,75 ГБ bf16) обслуживается чисто-растовским движком mistral.rs 0.9.5 — без llama.cpp, без Python. Движок живёт как локальный актор-процесс с OpenAI-совместимым эндпоинтом; в интерфейсе — кнопка ✨ на любой картинке-вложении: распознанный текст дописывается в заметку абзацем. Распознать скан чека или фото доски — секунды на современном ноуте, и всё это без единого сетевого вызова.

**STT — whisper внутри приложения.** tiny/base/small крутятся в процессе на candle (чистый Rust, CPU), декодер с OpenAI-правилами таймстемпов перенесён из candle-examples, аудио парсит встроенный RIFF/WAVE-парсер (8/16/24/32-бит PCM и float, любое число каналов) с ресемплингом в 16 кГц. Русский включается токеном `<|ru|>`. Точка входа — «Расшифровать запись» под аудио-блоком: транскрипт ложится обратно в блок.

**TTS — русские голоса через sherpa-onnx.** Piper VITS голоса Ирина и Дмитрий; sherpa-onnx 1.12.40 подгружается рантаймом с рукописным FFI (раскладки структур сверены с c-api.h этого тега). Кнопка 🔊 в редакторе озвучивает страницу, звук идёт через уже существующий rodio-плеер. На CPU ~3 секунды русской речи синтезируются за ~1,2 с.

**Просмотр PDF и картинок.** pdfium (загружается из каталога компонентов) — навигация по страницам и зум; PNG/JPEG/GIF/WebP декодируются крейтом `image` с зумом 20–500 % и панорамированием.

Важно архитектурно: компоненты ставятся в каталог данных приложения, **папка хранилища остаётся папкой `.eml`** — установка ИИ не добавляет в ваши данные ни одного служебного файла. Единственные не-растовские куски во всей истории — pdfium и sherpa-onnx, и это рантайм-библиотеки рендеринга/кодеков, а не движки инференса: сам инференс OCR и STT — чистый Rust.

### База, на которой это построено

**Формат.** `.eml` — не «экспорт», а родной формат: заголовки по RFC 5322, данные в MIME-частях с `Content-ID`, иерархия страниц в `X-Capsule-Page-Parent`. Инвариант закреплён в коде: каждый байт должен проходить туда-обратно через почтовый клиент. Если Thunderbird не может открыть файл — формат сломан.

**Редактор.** Блочный: заголовки, абзацы, чек-листы с датами и приоритетами, коллауты, код, CSV-датагриды, аудио-заметки, whiteboard с undo и рамочным выделением. `[[вики-ссылки]]` кликабельны, индекс обратных ссылок живой, переименование страницы переписывает ссылки по всему хранилищу. Автосохранение на каждое нажатие.

**Поиск.** Okapi BM25 по всему хранилищу: оценки релевантности, подсвеченные сниппеты, кириллический case-folding. «Похожие по смыслу» — tf-idf косинус по тому же индексу. Ни одного сетевого вызова.

**Планирование.** Все блоки задач из всех заметок собираются в один слой: Agenda, Kanban с drag&drop, Gantt со стрелками зависимостей, множественными блокировками и защитой от циклов, календарь и экспорт RFC 5545 ICS.

**Аудио.** Запись с микрофона прямо из аудио-блока (cpal → 16-бит PCM WAV с живым индикатором уровня), воспроизведение с перемоткой и громкостью — и вишенка: записал голосом → whisper расшифровал → текст в заметке. Полностью локальный цикл «сказал → увидел текст».

**Шифрование и код.** Капсулы шифруются OpenPGP; REPL исполняет JavaScript, ячейки дата-грида считают формулы (`=SUM(A1:A5)` и арифметика с вложенными ссылками).

**Треды и импорт.** Ответ на заметку — настоящий дочерний `.eml` с `In-Reply-To`/`References`. Перетащите `.eml` из Gmail/Outlook/Thunderbird — импортируются байт-в-байт; есть синхронизация по IMAP и миграция готового Obsidian-хранилища (`--import-obsidian`).

**Co-Thinker и MCP.** Детерминированный локальный движок критикует тезисы (расплывчатые формулировки, перекосы аргументации, аномалии в данных) — без API-ключей. Нужен внешний агент — хранилище отдаётся по MCP: Claude, Cursor или любой MCP-клиент читает и ищет вашу базу на ваших условиях.

### Нативный шелл

Нативная сборка на Rust + egui, без браузерного движка: никакого WebKitGTK/WebView2/Electron. AppImage ~11 МБ с нулём вшитых библиотек (только glibc и X11/Wayland), сборки под Windows (msi/nsis/портативный zip) и macOS (arm64). Старт мгновенный, интерфейс на русском и английском, встроенный FAQ (F1) вместо фальшивых демо-заметок. 178 нативных unit-тестов, CI на каждый PR.

### Честно про ограничения

Не спрятаны в маркетинг, а лежат в LIMITATIONS.md: загрузки компонентов не умеют докачку (сорвавшийся на 90 % файл на 1,75 ГБ начнётся заново); OCR честно CPU-шный — секунд на современном ноуте, без GPU-пути в v1.12; движок mistral.rs запинает на 0.9.5 и обновляется только с релизом; транскрипция длинной записи занимает один джоб (UI не блокирует); TTS — качество piper-medium, скорость фиксирована; ICS-экспорт — только VTODO без будильников; в Gantt нет перетаскивания полосок. Приложение стартует пустым — намеренно.
